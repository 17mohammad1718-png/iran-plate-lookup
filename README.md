# 🔍 پلاک‌یاب هوشمند (Iran Plate Lookup)

PWA فارسی و کاملاً آفلاین برای رمزگشایی شناسه‌های عمومی ایران — نسخه ۳.۰

## امکانات

### 🚗 پلاک خودرو
- تشخیص استان، شهر و نوع پلاک از کد دو رقمی، کد + حرف یا پلاک کامل
- دیاگرام شبیه‌سازی‌شده پلاک با رنگ‌بندی واقعی (شخصی، تاکسی، دولتی، نظامی، دیپلماتیک…)
- **اسکن پلاک با دوربین** (OCR با Tesseract.js — فارسی) یا انتخاب عکس
- جستجوی معکوس: انتخاب استان → دیدن کدها و حروف
- **نقشه تعاملی ایران**: هایلایت استان شناسایی‌شده + کلیک روی استان برای دیدن کدها

### 🪪 کد ملی
- محل صدور شناسنامه از سه رقم اول
- **اعتبارسنجی رقم کنترل (الگوریتم mod 11)** با کد کامل

### 🏍️ موتورسیکلت
- تشخیص استان از کد سه رقمی پلاک موتور

### 🔎 سایر شناسه‌ها
| شناسه | چه چیزی مشخص می‌شود |
|---|---|
| کد پستی ۱۰ رقمی | استان (رقم اول)، استان (دو رقم اول)، شهر (سه رقم اول — شهرهای اصلی) |
| کارت بانکی ۱۶ رقمی | بانک صادرکننده (۶ رقم اول BIN) + اعتبارسنجی Luhn |
| شماره شبا | بانک (کد ۳ رقمی) + اعتبارسنجی MOD 97 |
| موبایل ۱۱ رقمی | اپراتور (همراه اول، ایرانسل، رایتل، شاتل، لوتوس) |
| تلفن ثابت | استان/مرکز از کد مخابرات (۳۱ استان) |

### 🎨 ظاهری
- تم روشن/تاریک (خودکار بر اساس سیستم + دکمه دستی)
- ناوبری پایین (Bottom Navigation) موبایلی
- **کارت اشتراک تصویری**: خروجی PNG با دیاگرام پلاک برای واتساپ/تلگرام
- تاریخچه محلی، اشتراک متنی، راهنماهای کامل، PWA آفلاین

## 🔒 حریم خصوصی
این ابزار فقط **کدگذاری‌های عمومی و منتشرشده** (جداول مخابرات، پست، بانک مرکزی و…) را رمزگشایی می‌کند. هیچ اطلاعات هویتی، مالکیتی یا سوابق شخصی را استعلام نمی‌کند و همه داده‌ها روی دستگاه کاربر می‌ماند.

## 📊 منابع داده
- پلاک و کد ملی: ویکی‌پدیا و منابع عمومی (تقریبی)
- کد تلفن ثابت: جدول رسمی همسان‌سازی مخابرات
- کد پستی: جداول عمومی شرکت پست
- BIN کارت و کد شبا: جداول عمومی بانکی
- اپراتورهای موبایل: جداول عمومی اپراتورها
- نقشه ایران: استخراج‌شده از پکیج [iran-map](https://github.com/alithecodeguy/iran-map) (مجوز MIT) — برگرفته از نقشه TUBS (CC BY-SA)
