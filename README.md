# 🔍 پلاک‌یاب هوشمند (Iran Plate Lookup)

PWA فارسی، آفلاین و بدون بک‌اِند برای رمزگشایی شناسه‌های عمومی ایران — نسخه ۶.۰

## نسخه ۶.۰ — بازنویسی موبایل‌محور

- **بدون زوم ناخواسته**: همه ورودی‌ها ۱۶ پیکسل‌اند تا سافاری iOS موقع تایپ صفحه را زوم نکند (و `maximum-scale` برداشته شد تا زوم دستی کاربر آزاد بماند).
- **تاچ‌تارگت‌های استاندارد**: حداقل ۴۸ پیکسل برای همه دکمه‌ها، چیپ‌ها، آیتم‌های تاریخچه و ورودی‌ها.
- **کیبورد هوشمند**: `inputmode="numeric"` و `enterkeyhint="search"` روی همه فیلدها؛ بعد از جستجو کیبورد بسته و صفحه روی نتیجه اسکرول می‌شود.
- **توست به‌جای alert**: پیام‌ها دیگر دیالوگ سیستمی مزاحم نیستند + لرزش کوتاه (Haptic) هنگام نمایش نتیجه.
- **Safe Area کامل**: رعایت ناچ و نوار خانه در چپ، راست و پایین صفحه.
- **ریسپانسیو چندلایه**: بریک‌پوینت‌های ۳۳۰ / ۴۰۰ / ۶۴۰ پیکسل + حالت افقی موبایل + احترام به `prefers-reduced-motion`.
- **نقشه بهینه**: `:hover` فقط روی دستگاه‌های دارای ماوس (رنگ روی موبایل گیر نمی‌کرد)، مرزهای ضخیم‌تر و برچسب‌های بزرگ‌تر روی صفحه کوچک؛ نقشه هر تب فقط هنگام باز شدن آن ساخته می‌شود.
- **تم هوشمند**: تغییر رنگ کل برنامه متناسب با تب فعال (پلاک، کد ملی، موتور، شناسه‌ها).
- **ارتقای شناسه‌ها**: اعتبارسنجی دقیق کارت بانکی (Luhn)، شبا (MOD 97) و کد ملی (MOD 11).
- **کارت اشتراک**: تولید PNG ۱۰۸۰×۱۳۵۰ با رنگ اختصاصی تب.

### 🚗 پلاک (خودرو و موتورسیکلت)
- **ورودی به شکل خودِ پلاک**: خانه‌های جدا با نوار آبی «I.R.IRAN» و کادر «ایران + کد استان» — دقیقاً چیدمان پلاک واقعی
- **دو حالت با یک سوییچ**: 🚗 خودرو (پیش‌فرض) و 🏍️ موتورسیکلت
- پرش خودکار بین خانه‌ها، پشتیبانی از ارقام فارسی، Backspace به خانه قبل
- **پاک شدن خودکار ورودی بعد از جستجو** — بلافاصله آماده پلاک بعدی
- کد استان از دو رقم زیر کلمه «ایران» خوانده می‌شود (مطابق پلاک واقعی)
- دیاگرام شبیه‌سازی‌شده پلاک با رنگ‌بندی واقعی (شخصی، تاکسی، دولتی، نظامی، دیپلماتیک…)
- جستجوی معکوس: انتخاب استان → دیدن کدها و حروف
- **نقشه تعاملی ایران**: هایلایت استان شناسایی‌شده + لمس استان برای دیدن کدها

### 🪪 کد ملی
- محل صدور شناسنامه از سه رقم اول
- **اعتبارسنجی رقم کنترل (الگوریتم mod 11)** با کد کامل

### 🔎 سایر شناسه‌ها
| شناسه | چه چیزی مشخص می‌شود |
|---|---|
| کد پستی ۱۰ رقمی | استان (رقم اول)، استان (دو رقم اول)، شهر (سه رقم اول — شهرهای اصلی) |
| کارت بانکی ۱۶ رقمی | بانک صادرکننده (۶ رقم اول BIN) + اعتبارسنجی Luhn |
| شماره شبا | بانک (کد ۳ رقمی) + اعتبارسنجی MOD 97 |
| موبایل ۱۱ رقمی | اپراتور (همراه اول، ایرانسل، رایتل، شاتل، لوتوس) |
| تلفن ثابت | استان/مرکز از کد مخابرات (۳۱ استان) |

### 🎨 ظاهری
- تم روشن/تاریک (خودکار بر اساس سیستم + دکمه دستی)
- نوار تب چسبان بالای صفحه که هنگام اسکرول جمع می‌شود
- **کارت اشتراک تصویری**: خروجی PNG با دیاگرام پلاک برای واتساپ/تلگرام
- تاریخچه محلی، اشتراک متنی، راهنماهای کامل، PWA آفلاین (نصب روی صفحه اصلی گوشی)

## 🔒 حریم خصوصی
این ابزار فقط **کدگذاری‌های عمومی و منتشرشده** (جداول مخابرات، پست، بانک مرکزی و…) را رمزگشایی می‌کند. هیچ اطلاعات هویتی، مالکیتی یا سوابق شخصی را استعلام نمی‌کند و همه داده‌ها روی دستگاه کاربر می‌ماند.
